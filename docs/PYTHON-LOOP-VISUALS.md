# Python loop demonstrations

Python loop lessons previously passed visual validation with a generic graph of concepts. That graph did not represent execution; moving a dot along a connection did not demonstrate a loop.

`prepareProgrammingScenes` routes Python-loop beats without supplied code to bounded illustrative examples. `PythonExecution` renders deterministic execution traces: active line, iteration/condition state and accumulated output. No generated Python is executed. Existing narration, captions and timeline remain unchanged.

Supported demonstrations: list iteration over 1/2/3, three repeated actions with `range(3)`, a counter-based while loop and a while loop accepting example user input until `yes`. Other code retains the code renderer; this is not a general Python interpreter or a guarantee that unrelated topics have custom animations.

`apps/api/scripts/repair-python-loops.ts REVISION_ID` repairs a ready revision using its existing audio. It backs up the plan and MP4 before rendering; it saves the updated database plan only after the renderer completes its media/audio checks. Use the appropriate environment file for the profile being repaired.
